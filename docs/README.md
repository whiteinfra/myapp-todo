# MyApp 1.0.0 — посібник користувача

## Головне вікно

| Елемент | Призначення |
|---|---|
| Рядок «Завдання / Пріоритет / Дедлайн» і кнопка **Додати** | Створення нового завдання. Дедлайн необов’язковий: щоб його задати, поставте позначку біля дати |
| Перемикачі **Усі / Активні / Виконані** | Фільтр списку |
| Поле **Пошук** | Показує завдання, що містять введений текст (без урахування регістру) |
| Список | ✓ — виконано; червоний — прострочено; жирний — високий пріоритет. Клік по заголовку стовпця сортує список |
| **✓ Виконано**, **Редагувати**, **Видалити**, **Очистити виконані** | Дії з вибраним завданням або списком |
| Рядок стану | Кількість усіх, активних, виконаних і прострочених завдань і шлях до файлу даних |

## Клавіші

| Клавіша | Дія |
|---|---|
| Enter у полі «Завдання» | Додати завдання |
| Пробіл | Позначити вибране завдання виконаним (або зняти позначку) |
| Delete | Видалити вибране завдання (з підтвердженням) |
| Подвійний клік | Редагувати завдання |
| Ctrl+S | Зберегти (дані й так зберігаються після кожної дії) |
| F1 | Про програму |

## Де зберігаються дані

У файлі `%APPDATA%\MyApp\tasks.tsv` — це текстова таблиця з роздільником табуляції, яку можна відкрити в Excel. Меню **Файл → Відкрити теку з даними** відкриває цю теку в Провіднику. Під час першого запуску програма створює три приклади завдань.

## Часті питання

**Чи потрібен інтернет?** Ні, програма працює повністю локально.

**Що буде з даними після видалення програми?** Файл даних залишається на місці, і після повторного встановлення список відновиться.

**Програма не запускається.** Перевірте, що встановлено .NET Framework 4.8 (Параметри → Програми → Додаткові компоненти) і що використовується 64-розрядна Windows 10/11.
