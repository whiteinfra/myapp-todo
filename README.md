# MyApp — менеджер справ для Windows

[![build](https://github.com/whiteinfra/myapp-todo/actions/workflows/build.yml/badge.svg)](https://github.com/whiteinfra/myapp-todo/actions/workflows/build.yml)

**MyApp** — настільна програма для Windows, яка допомагає вести список справ: завдання з пріоритетом і дедлайном, позначення виконаних, фільтри, пошук і сортування. Це Windows-версія застосунку To-Do з лабораторної роботи № 6, розповсюджувана через інсталятор `MyAppInstaller.exe` (NSIS).

## Призначення

- швидко записувати завдання й не забувати про дедлайни (прострочені завдання підсвічуються червоним);
- бачити, що вже зроблено, а що ще ні (фільтри «Усі / Активні / Виконані» і пошук);
- зберігати список між запусками без бази даних і підключення до інтернету.

## Мінімальні вимоги

| Компонент | Вимога |
|---|---|
| ОС | Windows 10 (версія 1903 і новіші) або Windows 11, 64-розрядна |
| .NET | .NET Framework 4.8 — уже входить до складу Windows 10/11, окремо встановлювати не потрібно |
| Диск | 1 МБ для програми + дані користувача |
| Права | адміністратора — лише для встановлення та видалення |

## Встановлення

Завантажте `MyAppInstaller.exe` зі сторінки [Releases](https://github.com/whiteinfra/myapp-todo/releases) і запустіть його. Докладна інструкція, тихе встановлення й видалення описані в [INSTALL.md](INSTALL.md).

## Приклад запуску

1. Запустіть програму ярликом **MyApp** на робочому столі або в меню «Пуск» (чи `"C:\Program Files\MyApp\myapp.exe"`).
2. Введіть текст завдання, наприклад «Здати звіт з ЛР12», виберіть пріоритет «Високий», поставте позначку біля дати й виберіть дедлайн.
3. Натисніть **Додати** (або Enter) — завдання з’явиться в списку й одразу збережеться.
4. Виберіть завдання і натисніть **✓ Виконано** (або пробіл): рядок стане сірим і закресленим.

Довідка з командного рядка:

```bat
"C:\Program Files\MyApp\myapp.exe" --version     :: MyApp 1.0.0
"C:\Program Files\MyApp\myapp.exe" --selftest    :: самоперевірка логіки (використовується в CI)
```

Посібник користувача — [docs/README.md](docs/README.md).

## Збірка з вихідного коду

| ОС | Команда | Що потрібно |
|---|---|---|
| Windows | `build.cmd` | компілятор `csc.exe` з .NET Framework 4 (є у Windows) і [NSIS 3](https://nsis.sourceforge.io/Download) |
| Linux | `./build.sh` | `mono-mcs`, `mono-devel`, `nsis` |

Результат: `app\myapp.exe` і `installer\MyAppInstaller.exe`.

## Структура проєкту

```
myapp-todo/
├─ app/
│  ├─ src/MyApp.cs, app.ico   # вихідний код (C#, Windows Forms) і значок
│  └─ myapp.exe               # зібрана програма (створюється збіркою)
├─ docs/README.md             # посібник користувача (встановлюється разом із програмою)
├─ installer/
│  ├─ myapp_installer.nsi     # сценарій інсталятора NSIS
│  └─ MyAppInstaller.exe      # зібраний інсталятор
├─ README.md, INSTALL.md, CHANGELOG.md, RELEASE_NOTES.md, LICENSE.txt
├─ build.cmd, build.sh        # збірка програми й інсталятора
└─ .github/workflows/         # CI: збірка, самоперевірка, тест інсталятора на Windows, реліз
```

## Неперервна інтеграція

Workflow `build.yml` на кожен push збирає програму й інсталятор на Ubuntu (Mono + NSIS) і запускає самоперевірку `--selftest`. Потім на `windows-latest` у тихому режимі встановлює програму, перевіряє файли, ярлики й записи реєстру та видаляє її. Для тегу `v*` інсталятор публікується в GitHub Releases. Workflow `autofix.yml` разом із pre-commit автоматично виправляє зайві пробіли й кінці рядків.
