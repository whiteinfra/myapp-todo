## [1.0.0] - 2026-11-08

### Added

- Initial version — перша версія програми MyApp для Windows (Windows Forms, .NET Framework 4.8).
- Завдання з пріоритетом (високий, середній, низький) і необов’язковим дедлайном.
- Позначення виконаних, редагування, видалення з підтвердженням, очищення виконаних.
- Фільтри «Усі / Активні / Виконані», пошук без урахування регістру, сортування за стовпцями.
- Підсвічування прострочених завдань, рядок стану зі статистикою.
- Автоматичне збереження в `%APPDATA%\MyApp\tasks.tsv` (атомарний запис).
- Самоперевірка логіки `myapp.exe --selftest` і довідка `--version`.
- Інсталятор NSIS `MyAppInstaller.exe`: майстер українською, вибір компонентів, ярлики, записи в реєстрі, деінсталятор і запис у «Програмах та компонентах».
- Документація: README, INSTALL, CHANGELOG, RELEASE_NOTES, посібник користувача.
- CI у GitHub Actions: збірка, самоперевірка, тест встановлення й видалення на Windows, публікація релізу.
